## 1. تشكيل سرب المراجعة المتخصص (The 7 Goldfish Review Swarm)

| الوكيل المتخصص | الدور الرقابي | القرار والتقييم |
| :--- | :--- | :---: |
| **1. وكيل نسب الشاشات (Viewport & Aspect Ratio Agent)** | فحص أبعاد 21:9 و 19.5:9 و 16:9 وحواف الأمان السفلية والعلوية | ✅ معتمد بعد تضمين حواف السلة والفوتر |
| **2. وكيل إجهاد الخطوط (Typography Stress & Overflow Agent)** | فحص التكبير الحركي (120%-150%) وحظر اقتصاص الأرقام المالية | ✅ معتمد بعد إزالة `truncate` ودعم `flex-wrap` |
| **3. وكيل هندسة التبويبات والجداول (Tabs & Grid Layout Agent)** | تدقيق كبسولات التبويبات وشبكة المنتجات وسلة المبيعات | ✅ معتمد بعد تصحيح تكسير نصوص الكبسولات |
| **4. وكيل اللمس وبيئة العمل الميدانية (Touch Targets & Ergonomics Agent)** | التحقق من معيار مساحات اللمس (>= 44px × 44px) وتفادي الاصطدام الحركي | ✅ معتمد بعد ترقية أزرار الكميات والحذف والقوائم |
| **5. وكيل كيمياء الألوان والتباين (Theme & Contrast Auditor)** | فحص تباين WCAG AA في وضعي الداكن والفاتح والسمات الساطعة | ✅ معتمد بعد تصحيح `--primary-foreground` للسمات الفاتحة |
| **6. وكيل حماية الذاكرة العضلية والملفات المجمدة (Muscle Memory & Invariants Guard)** | حظر المساس بالملفات المجمدة وتثبيت مواقع أزرار الكاشير | 🟢 **GREEN LIGHT / APPROVED** |
| **7. وكيل تدقيق كود الواجهات والتعديل الجراحي (CSS/Tailwind Surgical Quality Critic)** | مطابقة الكود مع Tailwind ونقاط التوقف ومنع تعارضات الخصائص | ✅ معتمد بعد اعتماد `min-[380px]` وحذف الفئات العشوائية |

## 2. جدول القرارات الهندسية المعتمدة لحل كافة الملاحظات (Resolutions & Hardened Directives)

| المعرف | الملاحظة المرصودة | قرار السرب المعتمد | التنفيذ الجراحي المحدد |
| :--- | :--- | :--- | :--- |
| **RES-01** | اقتصاص الأسعار المالية عبر `truncate` في `ProductGrid.tsx:105` | **إزالة فورية ومطلقة لـ `truncate`** | استبدال `truncate` و `min-w-0` بـ `shrink-0 whitespace-nowrap font-black text-primary` لتظهر خانات السعر كاملة دائماً وتخضع لحجم الخط الممرر. |
| **RES-02** | استخدام نقطة توقف غير معرفة `xs:grid-cols-3` في `ProductGrid.tsx` | **اعتماد نقطة توقف اعتباطية قياسية** | استخدام `grid-cols-2 min-[380px]:grid-cols-3` لمنع تعطل Tailwind JIT وتحقيق التوازن في الشاشات فائقة النحافة (Sony Xperia). |
| **RES-03** | حجم شارة الكمية الضخم في النمط المكثف (`h-7 min-w-[2.25rem] text-[0.875rem]`) | **تقليص متناسق للنمط المكثف** | تحويل الشارة إلى `h-5 min-w-[1.5rem] px-1 text-[10px] font-bold rounded-md` لمنح السعر واسم المنتج المساحة الأساسية. |
| **RES-04** | صغر أزرار التحكم بالكمية `w-6 h-6` (24px) في `CartPanel.tsx` وتضاربها بالإبهام | **ترقية مساحة اللمس إلى >= 44px** | تحويل الأزرار إلى `size-8 rounded-lg` مع فئة لمسية موسعة `after:absolute after:-inset-1.5` لضمان هدف لمس 44px مريح وآمن دون تضخيم الهيكل البصري. |
| **RES-05** | جمود عداد الكمية بـ `w-6` مما يسبب طفح الأرقام الكبيرة (100+) | **مرونة عرض العداد الرقمي** | استبدال `w-6` بـ `min-w-[1.5rem] px-1 w-auto text-center tabular-nums` ليتموج الحقل تلقائياً عند طلب كميات الجملة. |
| **RES-06** | صغر زر حذف عنصر السلة (32px) وزر تبديل الوحدة (14px) | **ترقية وتأمين أهداف اللمس** | ترقية زر الحذف إلى `w-9 h-9` مع منطقة لمس 44px، وتكبير زر تبديل الوحدة إلى كبسولة تفاعلية مريحة. |
| **RES-07** | تداخل زر الخيارات ثلاثي النقاط في `Invoices.tsx` مع نصوص الفاتورة عند تكبيره | **عزل الزر وتوسيع الحشوة** | ترقية زر `MoreVertical` إلى مساحة لمس 44px (`w-10 h-10` أو `p-2`) مع زيادة حشوة بداية السطر المقابل إلى `pl-12` (أو `ltr:pl-12 rtl:pr-12`). |
| **RES-08** | تكسر نصوص كبسولات التبويبات عند التمرير الأفقي في `SegmentedCapsule.tsx` | **فصل نمط التمرير الصريح** | تعريف `capsuleScrollItem` بـ `whitespace-nowrap shrink-0 flex-none px-3.5 min-h-10 text-xs font-bold` وإزالة `whitespace-normal` المسببة لتكسر الكلمات عمودياً. |
| **RES-09** | اختناق ميزانية الارتفاع لسلة الموبايل وغياب حافة الأمان السفلية في `CartPanel.tsx` | **اعتماد `h-[90dvh]` و `safe-area` السفلية** | تطبيق `h-[90dvh] max-h-[calc(100dvh-env(safe-area-inset-top,0px))]` لدرج السلة، وإضافة `pb-[max(0.75rem,calc(env(safe-area-inset-bottom,0px)+0.5rem))]` لتذييل الدفع لمنع تداخله مع شريط إيماءات أندرويد. |
| **RES-10** | ضعف تباين النصوص فوق خلفيات السمات الساطعة (الليموني، البرتقالي، القهوة) | **تكييف ديناميكي لـ `--primary-foreground`** | تحديث `use-theme.tsx` ليضبط `--primary-foreground` كـ `222 47% 11%` (داكن عالي التباين) للسمات ذات السطوع العالي، والأبيض للسمات الداكنة. |
| **RES-11** | وجود ألوان صلبة غير نظامية (`bg-white dark:bg-zinc-900`) | **استئصال تام للألوان الصلبة** | استبدالها بـ `bg-card`, `bg-muted/60`, `border-border/50` المتوافقة 100% مع كافة سمات النظام. |
| **RES-12** | الحفاظ الصارم على الملفات المجمدة والذاكرة العضلية للكاشير | **تأكيد الحظر المطلق والجاهزية** | منع لمس ملفات المستودعات الثلاثة كلياً، وتثبيت أزرار الكاش والدين والسلال المعلقة والحاسبة بنفس مواقعها الحالية. |
